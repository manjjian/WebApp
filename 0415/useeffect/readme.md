개념코드설명
처음한번만실행useEffect(() => {...}, [])마운트시실행, 언마운트시정리
특정상태가변경될때실행useEffect(() => {...}, [state]) state 값이바뀔때실행
매렌더링마다실행useEffect(() => {...})의존성배열이없으면렌더링마다실행
언마운트시실행useEffect(() => { return () => {...}; }, [])컴포넌트가제거될때실행
컴포넌트가처음랜더링될때실행
특정상태가변경될때실행
